# AR Car Showcase

An Augmented Reality car showcase project built with Unity and Vuforia Engine.

## Overview

AR Car Showcase is a mobile AR experience that allows users to detect an image target and display a 3D vehicle model in the real environment.

The project focuses on:

- Image Target based AR tracking
- 3D vehicle model visualization
- AR object placement and scaling
- Mobile AR interaction
- Vuforia Engine integration
- Unity-based Android development

## Features

- Image Target detection using Vuforia
- 3D car model displayed in AR
- Interactive AR model presentation
- Mobile AR camera experience
- Optimized Unity project structure
- Android build support

## Technologies

- Unity
- C#
- Vuforia Engine
- AR Foundation / XR packages
- Universal Render Pipeline
- Git
- Git LFS
